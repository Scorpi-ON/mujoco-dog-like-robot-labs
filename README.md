# Go2 MuJoCo Labs

Учебный проект по программированию собакообразного робота Unitree Go2 в MuJoCo на Python. Проект теперь состоит из отдельных лабораторных работ: каждая лабораторная сама загружает нужную сцену и открывает визуализатор.

## Запуск

Лабораторные запускаются напрямую:

```powershell
uv run labs/lab1.py
uv run labs/lab8.py
uv run labs/lab11.py
```

В обычном режиме каждая лабораторная открывает MuJoCo viewer. Для продолжения нужно закрыть окно визуализатора.

## Структура

- `controllers/` - контроллеры стойки, простой походки и ONNX-политики движения.
- `labs/` - 11 лабораторных работ; каждая сохраняет артефакты и открывает визуальную демонстрацию.
- `vendor/unitree_rl_mjlab` - исходная модель Unitree Go2 и MJCF-сцены.
- `vendor/unitree-go2-velocity-flat` - предобученная управляющая политика в формате ONNX.

## Порядок Появления Объектов

Сцены сделаны поэтапно, чтобы студенты не видели объекты до их объяснения:

- `lab1`: только робот и базовый пол.
- `lab2`: учебная сцена редактирования MJCF с плоским маркером, полосой маршрута, стеной и небольшой горкой.
- `lab3`: появляется более крутая наклонная платформа для демонстрации стойки.
- `lab4`: робот снова стоит на ровном полу; демонстрируется плавное управление суставами.
- `lab5`: появляется линейный маршрут из двух плоских точек и плоской линии между ними.
- `lab6`, `lab10`: используется прямоугольный маршрут с плоскими точками и линиями.
- `lab7`: робот идет навстречу стене и периодически записывает лучевое расстояние.
- `lab8`: отдельная удлиненная линия с шестью цветными стенами: красная, красная, синяя, красная, синяя, синяя.
- `lab9`: появляется более крутая наклонная плоскость вверх/вниз.
- `lab11`: полная сцена с маршрутом, горкой, расписанием скоростей, синей стеной после первого поворота и красной стеной после второго.

## Лабораторные

1. Знакомство с MuJoCo и моделью Go2.
2. Редактирование мира: маркер, полоса, стена и горка.
3. Состояние симуляции и выравнивание корпуса на наклонной платформе.
4. ПД-регулятор суставов и плавное сгибание/разгибание ног на ровном полу.
5. Устойчивая ходьба по прямой линии из начальной точки в конечную.
6. Маршрут из waypoint-точек.
7. Движение к стене с разреженной записью лучевого расстояния.
8. Обход шести стен по цвету: красная стена - вправо, синяя - влево.
9. Наклонная плоскость и контакт с поверхностью.
10. Управляющая ONNX-политика и смена скорости: x2, x2, x1, x0.5.
11. Интеграционный прогон: горка, скорости, синяя и красная стены с обходом по цвету.

Артефакты сохраняются в `artifacts/labNN/`. По CSV и текстовым отчетам студент должен делать выводы о высоте корпуса, крене, переключении целей, обнаружении препятствия, направлении обхода и завершении маршрута.
